AI changes how software is made. It still runs on data. We build the tools,
infrastructure and data that products stand on, starting with the ones we needed
ourselves.

### How we work

- **First principles.** Question the step everyone takes for granted.
- **Traceable by default.** Every number leads back to where it came from.
- **Research first.** Products ship when they have earned it.

Everything we ship runs on our own hardware, on a rack in a home-office closet
in Kyoto. [Peek inside](https://rowandreason.com/closet/).
